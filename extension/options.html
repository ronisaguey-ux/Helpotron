Capture behavior

When does Helpotron capture a page?
  • Only when you click Scrape in the extension popup (or start a chat-context scrape)
  • Nothing is read or saved on page open, and nothing is captured on its own

Privacy

What a capture sends to your Helpotron account
  • Page URL and title of the page you scrape
  • Assignment prompt and rubric text found on the page
  • Course name and metadata used to file the material
  • File links on the page, plus file size and SHA-256 hash; the file itself when it is under 6 MB
Chat mode sends your messages and, when you turn on “See screen”, a compressed screenshot of the selected tab. Keystrokes you type into pages are never read. Full details: see the privacy policy linked below.
