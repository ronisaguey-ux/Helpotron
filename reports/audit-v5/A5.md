### Measured numbers (from code, not opinion)
- **Cost ledger double-write**: 1 `call_llm` with `db`+`user_id` from an authenticated request
  produced **2 `api_usage_logs` rows**, `$0.0048` settled against a `$0.0024` provider charge —
  **2.00x**. Two live call sites had this shape: `routes_overlord.py:2180`, `humanize_skill.py:520`.
- **Per-request prompt size** (`server/agent_session.py`): `AGENT_SYSTEM` 2,436 B + `TOOL_DOC`
  1,484 B = **3,920 B system prompt per step**; `_agent_prompt` sends the last 10 non-system
  messages, each truncated to 20,000 chars, so the tail is bounded at **~200,000 chars (~50k
  tokens) per step**, 120 steps max per session. Bounded, but that is the binding cap — not
  `MAX_PAGE_CHARS = 200000`.
- **Model identity notice**: `format_model_identity_prompt()` = **647 B (~161 tokens) on every
  single call**, prepended before the system prompt. Ordering is cache-friendly (the volatile
  `user_prompt` comes last), and it is constant per candidate model — reported as a measured cost,
  not a defect.
- **Pre-flight vs billing rates for gemini-3.8-flash**: $2.50/$7.50 per 1M estimated vs
  $1.00/$4.00 billed = **2.5x overstatement**; `estimate_task_cost` re-typed the numbers as
  literals so the table alone was not even the source of truth.
- **Admin cost summary**: 2 unbounded `SELECT ... FROM api_usage_logs` full-table scans per page
  load (one for totals/breakdown, one for `per_model`) -> now 3 aggregate queries (1 row each) +
  1 `created_at`-bounded window query.
- **Backups**: hourly timer x 30-day retention = up to **720 gzipped copies on the same disk**
  (~7.9 GB at the 11 MB backup size recorded in `plans/audit/prelaunch-checklist.md:36`); coverage
  is the SQLite file only — `uploads/`, `data_lake/`, `datalake_storage/` are copied by **no
  script** (the only `tar -czf` in `scripts/` is the frontend deploy).
